# Style District – Fashion E-commerce Website

**Style District** is a modern and elegant fashion e-commerce website designed to provide a smooth and enjoyable online shopping experience.

The project features a clean, minimalist design with a sophisticated color palette, focusing on usability, responsiveness, and interactive shopping functionality.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Home Page:** Modern landing page featuring promotional banners and featured products.
- **Shop Page:** Browse products with search, category filtering, and sorting options.
- **Product Details:** View product images, descriptions, prices, available sizes, and colors.
- **Shopping Cart:** Add products, update quantities, remove items, and calculate order totals.
- **Wishlist:** Save favorite products and manage your wishlist.
- **About Page:** Learn more about the brand, its story, and its values.
- **Contact Page:** Interactive contact form with basic input validation and confirmation message.
- **Local Storage:** Cart and wishlist data are saved in the browser using JavaScript Local Storage.

## Technologies Used

## Getting Started

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Important Notes

- Product data is currently managed through a JavaScript array.
- Cart and wishlist information are stored locally in the browser.
- The checkout process is currently a front-end demo and does not process real payments.
- The contact form displays a confirmation message but does not send actual emails.
